# Smart Energy Consumption Prediction Using Machine Learning

## Project Overview
This project explores residential electricity consumption data and uses machine learning to predict energy consumption. It includes model comparison, a trained prediction model, and visual analysis of model performance.

## Objectives
- Explore and preprocess electricity consumption data.
- Train and evaluate machine learning models.
- Compare model performance using evaluation metrics.
- Save the best-performing model for future predictions.
- Visualize model comparison results.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Scikit-learn
- Matplotlib
- Machine Learning

## Project Files

| File | Description |

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries based on the notebook imports.
3. Open `Neural.ipynb` in Jupyter Notebook or Google Colab.
4. Run the notebook cells in order.
